# Holley manual reference notes

User-specified reference manuals:

- Sniper EFI manual: https://documents.holley.com/techlibrary_199r11031r-1.pdf
- Troubleshooting guide: https://documents.holley.com/199r11369.pdf

Working interpretation notes used during this tuning sequence:

- Set throttle blade angle only once the engine is above 160°F.
- Warm/hot idle IAC target is generally 2-10%.
- If hot IAC is 0%, close the throttle blades; if hot IAC is above 10%, open the throttle blades.
- TPS should read 0% at closed throttle after idle screw changes; TPS autoset/reset may be needed.
- IAC Parked Position controls IAC position during cranking and immediately after start.
- If IAC parked position is too high, startup RPM will flare too high.
- Startup Hold Time controls how long IAC remains at the parked value.
- Startup Decay controls how quickly it returns from parked position toward normal idle control.
- Coolant enrichment acts like a choke: 100% is no extra fuel; 110% is 10% extra fuel.
- Large cam overlap can cause false lean readings at idle/low RPM.
- Closed loop and learn should be reintroduced carefully when O2 readings may be unreliable.
